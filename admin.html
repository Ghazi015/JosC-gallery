📖 Cara Deploy ke GitHub Pages

  1. Simpan file foto ke folder photos/ di repository lokal kamu.
  2. Klik "Tambahkan ke Galeri" → salin JSON yang dihasilkan.
  3. Buka file photos.json di repository, ganti isinya dengan JSON baru tersebut.
  4. Jalankan:
    git add .
    git commit -m "Add new photos"
    git push origin main
  5. Foto akan otomatis muncul di GitHub Pages dalam ±1 menit setelah push berhasil! 🌸
